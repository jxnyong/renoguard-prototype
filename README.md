# RenoGuard

*Renovate with proof, not promises.*

RenoGuard is a renovation management concept that helps homeowners understand quotations, track defects, and review the cost and timeline impact of changes before approving them.

This repository contains the high-fidelity frontend prototype for our SMU IS211 — Interaction Design and Prototyping project, building on our Iteration 1 low-fidelity prototype.

## Main Flows

- Review renovation quotations and costs by room.
- Report defects and track rectification progress.
- Review and approve renovation changes.

## Project Status

Work in progress. Screens and interactions will evolve through prototyping, testing, and feedback. Data and backend behaviour may be simulated.
